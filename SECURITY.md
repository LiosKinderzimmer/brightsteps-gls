# Sicherheit

- Keine GLS-Schlüssel, Passwörter, Cookies oder ERPNext-Zugangsdaten in Git speichern.
- Das GitHub-Repository muss privat bleiben.
- Der Softwarefirma genügt lesender Zugriff auf das Repository.
- Zugangsdaten werden ausschließlich verschlüsselt in den ERPNext-Einstellungen gespeichert.
- Version 0.3.1 ist nur für Testinstanz und GLS-Sandbox bestimmt.
- Produktionszugänge werden erst nach schriftlicher GLS-Freigabe und gesonderter Abnahme eingetragen.
